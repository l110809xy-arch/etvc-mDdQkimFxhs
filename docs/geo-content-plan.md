## 一、为什么按这个结构写

生成式引擎（ChatGPT / Gemini / Perplexity / 百度 AI / Google AI Overviews）取内容的方式与传统 SEO 不同：它不看你关键词密度，它找**可以直接摘出来当答案的段落**。所以每篇文章必须满足：

| 要素 | 要求 | 不达标的后果 |
|---|---|---|
| Answer First | 第一段就是完整答案，可独立成段被摘录 | AI 抓不到结论，转去引用别人 |
| Quantified Facts | 至少 3 个具体数字（学费、名额、年限、课时） | 回答变模糊，用户不信任 |
| Table Support | 对比/价格/流程一律用表格 | 段落里的数字容易被漏读 |
| Entity Consistency | 校名四语写法、地址、电话与 JSON-LD 完全一致 | 实体对不齐，AI 认为是两所学校 |
| Cite-able Chunk | 每个小标题下 80–150 字，不超过 3 句 | 太长会被截断，太短没有信息量 |

**事实基线（所有文章只能引用这些数字，不得自行发明）**

- 建校：2020 年，与老挝建国阵线（ແນວລາວສ້າງຊາດ）合作
- 学制：3 年制高等职业课程（Higher Diploma），第一学年 5 门课
- 上课时间：周一至周五 08:00–12:00
- 学费：第一年 6,300,000 / 第二年 6,930,000 / 第三年 7,245,000，三年合计 20,475,000 基普（LAK），可分 2 学期缴
- 奖学金：每年 50 个名额（优秀 / 贫困 / 少数民族）
- 地址：Ban Viengkham, Xaythany District, Vientiane Capital, Lao PDR
- 电话 / WhatsApp：+856 20 5825 8055、+856 20 5587 2937、+856 20 5995 9674
